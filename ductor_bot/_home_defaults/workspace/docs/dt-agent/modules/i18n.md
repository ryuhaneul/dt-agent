# i18n/

User-facing text of the bot, in nine languages. The language is the `language` config value (default `en`); it is applied once at startup and again when the value is hot-reloaded. Only text that reaches a person is translated: bot replies, notices, buttons, command descriptions and console output. Code, comments, logs, agent prompts and tool errors stay English.

## Files

- `i18n/__init__.py`: `init(language)`, `t(key, **kwargs)` (chat text), `t_rich(key, **kwargs)` (console text), `t_cmd(key)` (bot command descriptions), `t_plural(key, count, **kwargs)`; `LANGUAGES` maps a code to its own-language name. An unknown code falls back to `en`.
- `i18n/loader.py`: reads `<lang>/chat.toml`, `<lang>/cli.toml` and `<lang>/commands.toml`; a key missing in a language falls back to `en`.
- `i18n/check.py`: `python -m ductor_bot.i18n.check` compares every language with `en` (missing or extra keys, placeholder mismatches); it must report no gaps.
- `i18n/<lang>/`: `de en es fr id ko nl pt ru`.

## Style table

Every translation follows this table. A new key is written for all nine languages in the same change.

| Language | Addressing and tone | Reasoning effort | Notes |
| --- | --- | --- | --- |
| en | neutral | reasoning effort | reference text |
| de | du | Denkaufwand | `Provider` and `Session` are kept |
| es | tú | esfuerzo de razonamiento | |
| fr | tu | effort de raisonnement | |
| id | Anda | upaya penalaran | `kamu` only in the texts the user says to the agent |
| ko | polite informal (`해요체`); `~하세요` is allowed for commands | 추론 강도 | `provider` is kept; 세션, 모델, 토픽, 캐시, 시간 초과, 에이전트, 태스크 are translated |
| nl | je | redeneerinzet | `Time-out` |
| pt | você | esforço de raciocínio | keep accents |
| ru | ты | уровень рассуждений | `Таймаут` |

### Reasoning effort

The same term is used in every key that names the setting: `model.thinking_level` (title of the effort picker), `model.reasoning_line`, `model.effort_updated`, `status.effort_line`, `effort.select`, `effort.unsupported` and `commands:bot.effort`. The key `model.thinking_level` is not a separate concept: its buttons set `reasoning_effort`.

### Speakers

`welcome.prompt_*` and `welcome.btn_*` are written from the user to the agent, so they use the user's voice and are not changed to the bot's form of address.

### Labels

- Translate ordinary words: Timeout, Tokens (where the language has a word), Auth, Agents, Topics, Named, Where, Detail, Auto-Recovery.
- Keep product names and fixed terms: DT Agent, Claude Code, Grok Build, CLI, API, provider buttons.
- Technical borrowings follow the usage of the language. Words that are spelled the same in English and in the language (`Status`, `Detail`, `Model`, `Sessions`, `Maintenance`, `Description`, `Uptime`) are not untranslated text.

### Checks

`tests/i18n/test_quality.py` checks the reasoning-effort term, formerly untranslated sentences and the address form per language. Adding a language or changing a term means updating this table and that test.
